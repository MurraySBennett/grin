# GRIN Project Talks

A single route-aware HTML deck for the GRIN project, plus the planning documents
it was built from.

## Files

- `index.html`: the deck. Open it in a browser; no build step, no server.
- `MODULE_SPINE.md`: the shared project story and reusable content modules.
- `TALK_PROFILES.md`: audience- and venue-specific routes.
- `BUILD_PLAN.md`: the spec the deck was built against.
- `assets/`: figures copied from `results/figures/`.

## Using It

The toolbar sits bottom-left and fades until you hover it.

- **Profile** and **length** pick the route; slides filter themselves and the
  counter updates.
- **technical** and **DS** toggle the optional modules.
- **notes** shows presenter notes in the top-right.
- **dark** switches to a stage palette for a bright room.
- **Print** opens the browser print dialogue with one slide per page.

Arrow keys and space also move between slides.

## Numbers

Every figure quoted in the deck is the same value as the manuscript macro block
in `GRIN_combined_edited.tex`. If a pipeline stage is rerun, update both.
