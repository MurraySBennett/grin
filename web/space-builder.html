Space Builder

Set up a perceptual space, see the answers it produces, and test whether GRIN can recover it.

Imagine identifying a face as happy or sad and male or female at the same time. GRT says each face is represented in a two-dimensional perceptual space as a cloud rather than a single point, because perception is noisy. Each time you see the face, your impression is one point from that cloud. Your answer depends on which side of each line that point falls.

Two different things can tie the two features together. The clouds can move: if how happy a face looks depends on whether it is male, the features are not separable. The clouds can tilt: if, for one face, looking extra happy goes with looking extra male, the features are not independent. Drag the sliders to see both.

How much A's perceived value shifts depending on the level of B. Any value other than zero means A is not separable from B.

The perceptual space you built

Each ellipse is one stimulus: a 1-SD contour of where it lands in perceptual space on a given trial. The dashed cross is the decision bound. Your response depends on the quadrant your impression falls in.

Read the marginals. Each dimension's two curves of the same colour are the same level of that dimension, paired with the two different levels of the other one (solid vs dotted). If they sit on top of each other, that dimension is separable. If they pull apart, it is not.

Primary conclusions
What just happened?

GRIN drew 100 trials per stimulus from your space. This produced a noisy confusion matrix, which is a simulated experiment. GRIN then gave only that matrix to the network, which had never seen your sliders, and asked it to reconstruct the space.

Try this: set the trial count to 10 and run it a few times. The estimates jump around, and the ranges get wider. That is what should happen: a good method reports more uncertainty when it has less data.
