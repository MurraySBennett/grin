Analysing data you already have

From a trial-level CSV to a reportable fit.

You have an identification study: each row is a trial, with the stimulus shown and the response given. This turns that into a fitted perceptual space with intervals, and into the two construct probabilities a GRT analysis usually reports.

  1. Get your data into a 4×4 matrix

    Rows are stimuli, columns are responses, both in the canonical order A1B1, A1B2, A2B1, A2B2 — the second factor varies fastest. Order carries meaning that a bare matrix cannot express, so both packages refuse to guess: either pass it already ordered, or pass labels and let them resolve it. 

    import pandas as pd, grintools as gt

trials = pd.read_csv("my_experiment.csv")   # columns: stimulus, response
ci = gt.to_confusion(
    trials,
    stim_labels=["a1b1", "a1b2", "a2b1", "a2b2"],
    resp_labels=["a1b1", "a1b2", "a2b1", "a2b2"],
    long=True,
)
cm = ci.counts          # 4x4, canonical order

    library(grin)

trials <- read.csv("my_experiment.csv")   # columns: stimulus, response
ci <- grin_to_confusion(
  trials,
  stim_labels = c("a1b1", "a1b2", "a2b1", "a2b2"),
  resp_labels = c("a1b1", "a1b2", "a2b1", "a2b2")
)
cm <- ci$counts        # 4x4, canonical order

  2. Fit it

    One call. On a laptop this is a fraction of a millisecond, so fitting a hundred participants is not a thing you need to plan around. 

    fit, con = gt.infer(cm)

print(fit.summary())
print("P(perceptual independence) =", con["p_PI"])
print("P(separability on A)       =", con["p_sep_A"])
print("P(separability on B)       =", con["p_sep_B"])

    fit <- grin_infer(cm)

print(fit)
fit$constructs$p_PI
fit$constructs$p_sep_A
fit$constructs$p_sep_B

    Each construct also carries an evidence flag, true when the probability is far enough from one half to be worth reporting as a finding rather than as an open question.

  3. Report it

    The perceptual space with its decision bounds is the conventional way to present a GRT result, and it comes straight off the fitted object. 

    from grintools.plot import (plot_space, plot_params,
                            plot_constructs, plot_diagnostics)

plot_space(fit)             # the perceptual space
plot_params(fit)            # 12 parameters with credible intervals
plot_constructs(fit, con)   # construct probabilities
plot_diagnostics(fit, cm)   # predicted vs observed, all 16 cells

    res <- fit$result
con <- fit$constructs

grin_plot_space(res)             # the perceptual space
grin_plot_params(res)            # 12 parameters with credible intervals
grin_plot_constructs(res, con)   # construct probabilities
grin_plot_diagnostics(res, cm)   # predicted vs observed, all 16 cells

    Read plot_diagnostics carefully: a poor reconstruction is a real warning, but a good one does not validate the GRT assumptions. The unconstrained model can reproduce any pattern of response proportions, so fitting well is not evidence that the model is right.

  4. Do the whole sample

    fits = {}
for pid, sub in trials.groupby("participant"):
    ci = gt.to_confusion(sub, long=True,
                         stim_labels=["a1b1","a1b2","a2b1","a2b2"],
                         resp_labels=["a1b1","a1b2","a2b1","a2b2"])
    fits[pid] = gt.infer(ci.counts)

import numpy as np
p_pi = np.array([c["p_PI"] for _, c in fits.values()])
print(f"{(p_pi < 0.5).sum()} of {len(p_pi)} show evidence against independence")

    fits <- lapply(split(trials, trials$participant), function(sub) {
  ci <- grin_to_confusion(sub,
          stim_labels = c("a1b1","a1b2","a2b1","a2b2"),
          resp_labels = c("a1b1","a1b2","a2b1","a2b2"))
  grin_infer(ci$counts)
})

grin_tidy(fits)                       # one tidy row per parameter per person
grin_plot_space_group(lapply(fits, `[[`, "result"))
grin_plot_model_classes(lapply(fits, `[[`, "result"))

  5. Know what the intervals mean

    The interval on a marginal sensitivity means what it says. The interval on a within-stimulus correlation is narrower than nominal — across large held-out sets a 90% interval covers about 84% of the time. Both packages ship an optional correction, off by default: 

    fit, con = gt.infer(cm, calibrated=True)
fit.std          # corrected widths
fit.std_raw      # what the network returned

    fit <- grin_infer(cm, calibrated = TRUE)
fit$result$std        # corrected widths
fit$result$std_raw    # what the network returned

    Point estimates, construct probabilities and model selection are identical either way — only the stated uncertainty changes.
