Evidence

Recovery and calibration on ground-truth data.

What this page is for

The rest of the site analyses one dataset at a time. This page asks two questions across many simulated participants: does GRIN recover the true values, and are its uncertainty ranges the right width?

Because the data are simulated, the true answer is known for every participant, so the estimates can be checked directly against it. For the same kind of comparison on your own or published data, visit the Analyse page.

The manuscript-scale check

We tested GRIN on 24,000 simulated datasets that it had not seen during training. Its estimates of where each cloud sits (the eight location parameters) closely matched the true values, with a mean recovery correlation of 0.91. Its estimates of each cloud's tilt (the four within-stimulus correlations) matched less well, at 0.59.

The uncertainty ranges are reported separately for the two families, because they are calibrated differently. Ranges stated as 90% contained the true value 94.5% of the time for the sensitivities and 84.1% of the time for the correlations. A nominal 90% range on a within-stimulus correlation therefore behaves more like an 84% one. Pooling the two families averages errors that run in opposite directions and gives a figure near 90% that describes neither, so we do not quote one here.

These results come from the fixed research checkpoint reported in the paper, on test matrices spanning 5–500 trials per stimulus. The small live exercise below is for intuition and will vary from run to run; it uses the same browser weights as Analyse.

2. Calibration: do the intervals hold?

An interval is only useful if its stated coverage is right. For each stated level of confidence, a 50% interval, an 80% interval, and so on, this plots how often the true value actually fell inside. A calibrated method sits on the dashed diagonal: its 90% intervals contain the truth about 90% of the time. Bowing above the line is under-confidence and below it is over-confidence.

How to read this

The location estimates (sensitivities) sit close to the diagonal. The tilt estimates (correlations) scatter more, because a weak tilt barely changes the table of answers. The standard maximum-likelihood fit shows the same pattern; An independence problem explains why. With fewer trials per stimulus the points spread out, because the estimates become less certain and say so. In the calibration panel, expect the sensitivity curve to track the diagonal and the correlation curve to sit below it: those ranges are too narrow, which is the miscalibration the figures above report.
