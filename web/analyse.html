Real confusion matrices from the GRT literature, so you can see GRIN and a classical maximum-likelihood fit — the same estimator grtools and mdsdt implement — land on the same answer for data someone else already published.

Format

One row per trial: stimulus, response (as A1B1-style codes, your own labels like Happy/Male, or 0–3), optional participant, optional rt in seconds. Include rt to get architecture and accumulator estimates; omit it for the faster counts-only model.
